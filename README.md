# SenVT

A nostalgic videotext interface with remote control - for everyone who misses the good old days of teletext! 🎮 📺

## About the Project

SenVT is an interactive videotext system that brings back the classic era of teletext. With an authentic remote control and the characteristic "teletext" look & feel, immerse yourself in a time when television was still something special.

### Features

- 🎯 Authentic videotext navigation
- 🎮 Remote control interface
- 📺 Classic teletext layout
- 🔄 Real-time updates
- 🎨 Retro design

## Technology

- Frontend: React.js
- Styling: TailwindCSS
- State Management: Zustand
- Remote Control: Custom React Hook

## Installation

```bash
npm install
npm run dev
```

## Usage

1. Start the application
2. Use the remote control or your keyboard
3. Navigate through different pages
4. Enjoy the nostalgic experience!
